## 📂 Project Highlights

### ☁️ Backend & Automation (Go)
- **[Telegram Crypto Bot](telegram-bot)** – A multi-utility backend bot written in Go (Golang) that fetches live Bitcoin prices via REST API and handles user commands.
- **[Go Calculator](go-calculator)** – CLI calculator built in Go, focusing on type conversion and error handling (division by zero).
- **[Go Number Guessing Game](go-guessing-game)** – Mini-game using Go's `math/rand/v2` package for interactive CLI logic.

### 🖥️ Systems & Computer Vision (Python)
- **[Hand Gesture Controller](mouse)** – A Python script using OpenCV and MediaPipe to translate hand gestures into system mouse movements and clicks. *(Exploring system input automation).*
- **[Password Generator](passwird_gen.py)** – Generates cryptographically secure passwords using Python's `secrets` module.
- **[Poke-Fetch](api%20connect.py)** – Connects to PokéAPI to retrieve stats using the `requests` library (API and JSON parsing practice).

### 🖥️ GUI Applications & Games (Python)
- **[Calculator](calculator.py)** – Full Tkinter GUI with arithmetic operations and a clean grid layout.
- **[Runner Game](game.py)** – Pygame endless runner with gravity and collision detection.
- **[Planet Simulation](planets.py)** – Newtonian gravity simulation using Pygame and math.

### 📊 Data Visualization
- **[Dynamic Graph Maker](differentgrahp.py)** – Interactive Matplotlib tool for bar, line, scatter, and pie charts.
